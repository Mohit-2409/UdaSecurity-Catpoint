# 🛡️ Catpoint Security System

This is a desktop-based security system application built with Java Swing. It simulates a home security system that uses image processing to detect threats and trigger alarms accordingly. This project follows the modular structure and includes unit test coverage using JUnit and Mockito.

## 📦 Modules

- **catpoint-parent** — Parent Maven project managing dependencies and modules.
- **image-service** — Provides image analysis to detect threats.
- **security-service** — Main logic for the security system.
- **CatpointApp** — GUI application entry point.

## 🚀 Features

- Intruder and pet detection
- Alarm arming/disarming system
- GUI interface to simulate real-time security dashboard
- Modular Maven structure
- Unit test coverage for core logic
